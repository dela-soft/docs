# Docs

**Docs** — web-редактор для **автоматизации печатных форм и отчётов**: шаблоны документов, конструктор макетов, заполнение полей по данным.

Приложение проекта [DELTA+](https://github.com/dela-soft/delta). Помогает готовить печатные формы (приказы, списки, справки, договоры и другие документы) и строить отчёты по шаблону. Пример использования — в кадровом приложении [Staff](https://github.com/dela-soft/staff) («DELTA+ Персонал»).

Подробнее: [обзор](docs/ru/overview.md).
