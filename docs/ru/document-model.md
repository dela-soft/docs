# Модель документа

Краткая схема понятий Docs. Детали API и wire — по мере наполнения документации.

## Раздел (section)

Документ состоит из одного или нескольких **разделов**.

У раздела:

- единый **формат страницы** (размер, ориентация, поля);
- текстовый поток раздела и корневые объекты размещения.

Разный формат (например портретный и альбомный) — это **разные разделы**, идущие друг за другом, а не разные форматы внутри одного раздела.

## Страница (page)

Параметры листа раздела: ширина/высота, поля (margins), рабочая область внутри полей (`WorkWidth` / `WorkHeight`).

Координаты объектов размещения задаются **относительно рабочей области** (не включая поля). Поля учитываются при отрисовке листа.

## Размещение (placement)

Плавающие объекты на листе: текст, панели, фигуры и т.п.

- Корневые объекты принадлежат разделу.
- Объекты внутри **панели** задаются координатами относительно панели.

Примеры — в [examples/](../../examples/) (по мере появления файлов).
