# Docs — обзор

**Docs** — редактор макетов и отчётов проекта **DELTA+**.

## Зачем нужен

- Создавать и править шаблоны документов (макеты отчётов)
- Описывать автоматизацию создания шаблона через конструктор (`.dtc`)
- Формировать структуру документа
- Связывать поля с выражениями автоматизации (**dela**)
- Строить отчёт по шаблону (в т.ч. из сценариев **Staff**)

## Файлы

| Расширение | Назначение |
|------------|------------|
| `.dlt` | Макет / шаблон документа |
| `.dtc` | Описание автоматизации создания шаблона с помощью конструктора |

Точный контракт форматов и API будет дополняться по мере описания.

## Имена

| Где | Как называется |
|-----|----------------|
| Документация, продукт | **Docs** |
| Контейнер / сервис | `delta:docs` |

## В проекте DELTA+

См. [продукты и связи](https://github.com/dela-soft/delta/blob/main/docs/ru/products.md) в проекте **DELTA+**.

Кратко:

- **Docs** — создание и правка шаблонов (макет, конструктор, выражения **dela**)
- **Staff** использует шаблон документа для формирования отчёта с помощью Docs
