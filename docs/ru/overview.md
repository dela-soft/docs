# Docs — обзор

**Docs** — приложение-редактор макетов и отчётов проекта **DELTA+**. Предназначено для **автоматизации печатных форм**: шаблон документа описывается один раз, а данные подставляются при его формировании.

Типовые задачи: печатные формы кадрового учёта и делопроизводства, шаблоны договоров с контрагентами, списки, справки, статистические формы, отчёты с группировкой — без ручной вёрстки каждого экземпляра.

## Зачем нужен

- Создавать и править **шаблоны печатных форм и отчётов** (макеты документов)
- Описывать автоматизацию создания шаблона через конструктор (`.dtc`)
- Формировать структуру документа (разделы, страницы, размещение объектов)
- Связывать поля формы с выражениями автоматизации (**dela-script**)
- Строить готовый документ / отчёт по шаблону (в т.ч. из сценариев **Staff** — кадровый учёт)

## Файлы

| Расширение | Назначение |
|------------|------------|
| `.dlt` | Макет / шаблон документа (печатная форма, отчёт) |
| `.dtc` | Описание автоматизации создания шаблона с помощью конструктора |

Точный контракт форматов и API будет дополняться по мере описания.

## Имена

| Где | Как называется |
|-----|----------------|
| Документация, продукт | **Docs** |
| Контейнер / сервис | `delta:docs` |

## В проекте DELTA+

См. [продукты и связи](https://github.com/dela-soft/delta/blob/main/docs/ru/products.md) в проекте **DELTA+**.

Кратко:

- **Docs** — создание и правка шаблонов печатных форм (макет, конструктор, выражения **dela-script**)
- **Staff** («DELTA+ Персонал») использует шаблон и Docs для формирования кадровых документов и отчётов
