# Шрифты

Шрифты для редактора и PDF. Подхватываются при старте контейнера.

В комплекте — [Liberation](https://github.com/liberationfonts/liberation-fonts) (лицензия SIL OFL 1.1, см. `LICENSE-Liberation.txt`): по метрикам совпадают с Times New Roman, Arial и Courier New и доступны также под этими именами (если оригинальных шрифтов здесь нет).

Нужны другие шрифты — положите сюда свои `.ttf` / `.otf` и перезапустите контейнер.
